# Skills

Project skills for the Tindahang AI platform. Each skill is a directory containing a `SKILL.md` entrypoint.

Invoke directly with `/skill-name` or let Claude load automatically based on context.

## Available Skills

| Skill | When to use |
|-------|-------------|
| `building-with-medusa` | Core Medusa patterns (API routes, workflows, modules, links) |
| `building-admin-dashboard-customizations` | Admin widgets, routes, UI extensions |
| `adding-data-to-medusa` | Creating products, categories, regions, promotions |
| `fetching-medusa-product-data` | Product queries and data structures in storefronts |
| `designing-storefronts` | UI/visual changes, storefront aesthetics |
| `building-product-pages` | Product detail pages, galleries, variant selection |
| `implementing-checkout` | Checkout flows |
| `building-customer-login` | Customer accounts and authentication |
| `building-megamenus` | Mega menu navigation |
| `working-with-prices-and-money-amounts` | Prices, currency formatting |
| `working-with-product-images` | Product image handling |
| `configuring-regions-countries-currencies` | Regions, countries, multi-currency |
| `creating-promotions` | Sales, discounts, promotions |
| `creating-and-implementing-free-shipping` | Free shipping promotions |
| `using-emails` | Email with React Email templates |
| `implementing-newsletter-features` | Newsletter subscriptions |
| `integrating-third-parties` | Instagram, Google, Mailchimp integrations |
| `handling-complex-features` | Subscriptions, marketplaces, B2B, bundles |
| `seo-best-practices` | Meta tags, structured data, product schema |
| `fetching-external-websites` | Migrating content from external sites |
| `setting-initial-store-experience-for-users` | Initial store concept setup |
