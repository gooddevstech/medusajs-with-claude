# Initial Store Setup

## Required Steps (Do NOT skip any)

1. **Align on Bold Vision** - Load "designing-storefronts" skill
2. **Create Homepage** - Hero section, brand story
3. **Create 2-3 Products** - Use GenerateImage, NEVER Unsplash
4. **Create Product Details Page** - Match homepage aesthetic
5. **Align Base Template** - Navigation, footer, cart, typography, colors

## Data Fetching

MUST use server-side loading via TanStack Start loaders, NOT client-side fetch.

## Success Criteria

User loads storefront and immediately recognizes their vision - not a generic template.
