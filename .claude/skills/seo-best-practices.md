# SEO Optimization for Ecommerce Storefronts

## Every Product Page Needs

- Unique title and description
- Product schema with price, availability, rating
- Breadcrumb schema
- Canonical URL
- Descriptive image alt text
- Fast load time (LCP < 2.5s)

## Meta Tags Requirements

- **Title**: "Product Name - Key Feature | Store Name" (50-60 chars)
- **Description**: Key features + USP (150-160 chars)
- **Open Graph** tags for social sharing
- **Canonical URL** for variants and category paths

## Structured Data

Product Schema essential fields:
- name, description, image, sku, brand
- offers with price, priceCurrency, availability, priceValidUntil

## Core Web Vitals

- LCP < 2.5s
- CLS < 0.1
- INP < 200ms
